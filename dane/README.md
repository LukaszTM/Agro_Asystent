# dane (katalog roboczy, poza repozytorium)
Katalog na pliki pobierane i wytwarzane przez skrypty z `tools/`:

- `pobrane/` — pliki ze stron MRiRW i etykiety PDF (pamięć podręczna),
- `wynik/` — bazy i słowniki gotowe do dołączenia do aplikacji,
- `wnioski/`, `prywatne/` — materiał z danymi osobowymi; nigdy nie wersjonowany.

Cała zawartość jest wykluczona w `.gitignore` — zostaje tylko ten plik.
