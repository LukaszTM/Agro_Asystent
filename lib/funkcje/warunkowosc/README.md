# warunkowosc
Normy dobrej kultury rolnej (GAEC): liczenie zmianowania i dywersyfikacji (GAEC 7)
oraz okrywy ochronnej gleby (GAEC 6), razem z deklaracjami, które podaje rolnik.
Wszystkie progi, terminy i wyłączenia pochodzą ze słownika reguł — w kodzie nie ma
liczb z przepisu. Dane i logika; ekrany są w `lib/wyglad/*/`.
