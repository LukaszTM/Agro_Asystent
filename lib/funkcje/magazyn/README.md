# magazyn
Zakupy, zużycie i stan środków ochrony roślin oraz nawozów (premium, plan pkt 8).
Stan liczy się z ruchów, nie jest osobną liczbą do nadpisywania; zużycie przy zabiegu
dopisuje aplikacja z dawki i powierzchni, a czego nie umie policzyć — nie zgaduje.
Dane i logika; ekrany są w `lib/wyglad/*/`.
